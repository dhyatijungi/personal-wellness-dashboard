Frequently Asked Questions

Quick answers regarding the Personal Wellness Dashboard.

What is the Personal Wellness Dashboard?
The Personal Wellness Dashboard is a responsive, static web application engineered using semantic HTML5 and modern CSS3 for the Web Technology subject. It unites nutrition, fitness, sleep, mindfulness, and daily habits into a cohesive interface.
Is this website built strictly with HTML and CSS?
Yes! The entire architecture—including responsive mobile navigation, interactive tab filtering, habit checklists, and modal dialogs—is built cleanly with pure semantic HTML5 and CSS3 without requiring external JavaScript runtimes.
How does the 90-minute sleep cycle calculator work?
Human sleep traverses 4 distinct stages approximately every 90 minutes. Setting an alarm to wake up precisely between cycles avoids waking up during deep Slow-Wave Sleep (Stage 3), which causes morning grogginess (sleep inertia).
Are the workout routines safe for complete beginners?
Yes, our programs feature tiered intensity meters. Routines such as "Sunrise Yoga & Spinal Mobility" and the "Desk Posture Reset" are low-impact and designed for sedentary individuals or desk workers.
Where can I view the Administrator Control Panel?
You can click the Admin Portal button located at the top-right of any page or visit the Admin Dashboard directly to explore user management, workout libraries, recipe catalogs, and analytics.
